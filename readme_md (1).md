# React Counter App 🔢✨

A sleek, modern, and fully responsive **React Counter Application** featuring a glassmorphism (frosted glass) dark theme design, smooth interactive UI elements, and instant state updates.

## 🚀 Live Demo

Check out the live website deployed on Netlify:
👉 [**React Counter App Live**](https://react-counter-app284.netlify.app/)

---

## ✨ Features

* **Glassmorphism UI**: Built with a stylish frosted glass card layout and dark gradient backdrop.
* **Dynamic Visual Feedback**: Number color changes dynamically based on positive, negative, or zero values with glow effects.
* **Fully Responsive**: Perfectly calibrated layout that fills the screen seamlessly across Mobile, Tablet, and Desktop devices.
* **Limit Handlers**: Smooth state management using React's `useState` hook.
* **Pure React & Inline Styling**: Zero external CSS dependencies required, ensuring fast load times and clean rendering.

---

## 🛠️ Tech Stack

* **Frontend**: React.js
* **Build Tool**: Vite
* **Styling**: Modern Inline CSS & Glassmorphic Design Effects
* **Deployment**: Netlify

## ⚙️ Getting Started Locally

### Prerequisites

Ensure you have **Node.js** installed on your system.

### Installation Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/mrayanasif/counter.git
   ```

2. **Navigate into the Project Directory:**
   ```bash
   cd counter
   ```

3. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Run the Local Development Server:**
   ```bash
   npm run dev
   ```
